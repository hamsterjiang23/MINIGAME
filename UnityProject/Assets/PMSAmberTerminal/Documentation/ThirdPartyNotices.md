# Asset provenance · HTML calibration

- UI source, palette, layout and lifecycle are adapted from the user's approved HTML prototype v0.8.12. Its unmodified self-contained source is included in Reference/PMS_v0.8.12.html.
- Ward_Original.jpg is the ward image supplied by the user. Ward_WarmGray.png is the exact 464×261 processed monitor buffer exported from the HTML drawing code. No third-party game art has been added.
- Art/FontAtlas contains rendered UI glyph pixels and placement metrics produced at the original HTML sizes and colors using the local Windows SimSun and Lucida Console fonts. No Windows .ttf, .ttc, .otf or font installer is included. These pixels are not a substitute general-purpose font. The host keeps its prior Noto font and OFL notice for legacy API compatibility; the terminal glyph renderer uses the HTML bitmap atlas.
- Tools/HTML原字形导出.html is a self-contained Canvas tool for extending the fixed UI glyph set. It requires the original fonts on the authoring machine, not on the runtime player's machine.
- Phosphor_Line.png and Phosphor_Dot.png are generated gradient textures. UI_*.png are reusable frame/selection primitives. CRT is applied at runtime.
- Boot reference retained from the original HTML: DEC VAX 4000 Model 300 Installation (1990/1991), https://www.vaxhaven.com/images/8/8e/EK-335AC-IN-003.pdf . This package does not emulate VAX hardware or include DEC system software.
- CRT optical references retained from the original HTML: National Semiconductor AN-656 (November 1989), https://www.ti.com/lit/an/snla017/snla017.pdf ; https://patents.google.com/patent/US5903111A/en . The visual transition is an artistic approximation of display optics.
- Calibration/HTML_*_Raw.png are local Canvas2D executions of the reference HTML drawing code. HTML_*_CRTModel.png are numerical evaluations of its GLSL formulas, not browser GPU captures. Calibration/Gamma/Unity_* and Calibration/Linear/Unity_* are actual native Unity captures from an isolated validation project. Preview/Unity_* contains calibrated captures.

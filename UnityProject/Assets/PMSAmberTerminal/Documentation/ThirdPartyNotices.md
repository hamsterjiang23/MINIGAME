# Asset provenance

- Package UI source, palette, layout and lifecycle: exported/adapted from the user's HTML prototype v0.8.12. Generated UI code is provided with this package for the user's project.
- Ward_Original.jpg: the ward photograph supplied by the user in this conversation. Ward_WarmGray.png is the exact 464×261 processed monitor buffer exported from the HTML renderer. No third-party game artwork has been added.
- NotoSansMonoCJKsc-Regular.otf: unmodified Noto Sans Mono CJK SC from https://github.com/notofonts/noto-cjk , source file https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/Mono/NotoSansMonoCJKsc-Regular.otf . Its embedded copyright notices and font names remain intact. SIL Open Font License 1.1 is included at ../Fonts/OFL.txt. The font keeps its original license.
- Phosphor_Line.png and Phosphor_Dot.png: generated transparent gradient textures based on the package's native glow math.
- UI_*.png: generated reusable frame/selection primitives; CRT effects are applied at runtime, not baked into these sprites.
- Boot presentation reference: Digital Equipment Corporation, VAX 4000 Model 300 Installation, 1990/1991: https://www.vaxhaven.com/images/8/8e/EK-335AC-IN-003.pdf . This package does not emulate VAX hardware or ship DEC system software.
- CRT optical references: National Semiconductor AN-656 (November 1989), https://www.ti.com/lit/an/snla017/snla017.pdf ; spot-suppression circuit description https://patents.google.com/patent/US5903111A/en . This is an artistic visual transition, not an electronics simulation.
- Preview/HTML_*.png are reference renders of the original HTML. Preview/Unity_*.png, when present, are actual captures from the isolated Unity validation project. These are distinguished in the validation report.

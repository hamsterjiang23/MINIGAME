# Deviations

- 2026-10-21：按用户后续要求，阅读框从物体旁的固定世界位置改为相机右侧并保留1.5%视口边距；正文与边框保持白色，阅读时保留鼠标转向。
- 正文由34号调整为48号粗体，框线由2调整为3；每页按实际排版宽高加22内边距收拢边框，长文仍按完整文字分页。
- 景深感使用真实世界空间文字、透视与柔化光晕；为保持中文在现有8像素复古滤镜下可读，文字由后置透明相机绘制，不给整个房间增加失焦。

# Discovered edge cases

- 右侧空位不足时按物体投影避让至上方或下方；仍无可读空位时立即隐藏，保留当前页并阻止隐藏期间翻页，空间恢复后重新显示。
- 避让包含框内阴影；相机 LateUpdate 和实际合成前均重新定位，覆盖转向、镜头参数与截图目标比例变化。
- 阅读需要阻止移动、重复触发与结束当帧的点击穿透；暂停保留当前页，恢复后同一帧不继续。
- 场景切换、读档、宿主禁用和交互物消失必须撤销文字相机与输入占用。
- 首轮截图发现 Canvas 也会绘制材质的合成 pass；文字和相机合成现已分为两个 shader，避免白色矩形覆盖。
- 审查发现单段长文本可能被裁切；已复用现有文字排版分页器，并以整段逐页拼接还原验证没有丢句。
- 最终截图中短句末行仅剩少量字；分页前按文字测量收窄短段宽度，使两行更均衡，仍按实际区域分页。

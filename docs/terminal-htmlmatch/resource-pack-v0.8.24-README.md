# PMS UI 美术资源 v0.8.24 / 60% 图标定稿

对应本次确认的 HTML v0.8.24：800×600 琥珀终端，三个处置图标缩到上一版的 60%，整行选中反白，左侧监控和所有交互规则保留。没有采用前一次仅文字区反白的图片试验。

## 导入 Unity

1. 解压 ZIP，把 `Assets/PMSAmberUI_v0824` 连同 `.meta` 复制到工程的 `Assets`。不要把 ZIP 本身拖到 Project。此目录使用独立名称，不覆盖旧的 `PMSAmberTerminal` 或现有游戏代码。
2. 素材按原生像素使用。Canvas Scaler 参考分辨率设为 **800×600**；PNG 已设为 Point、无 Mipmap、无压缩、NPOT 不缩放。不要再次把三个小图标缩放 60%，缩小结果已经烘焙进 PNG。
3. 最省事的按钮做法：使用 `CommandRows` 中的完整行图片，按 Normal / Selected / Pressed / Disabled 绑定状态。行图片是 248×48，HTML 实际可点击区域为顶部 248×44。行图片已经包含名称和图标，不要再叠加一份。
4. 如果自行拆分布局，使用 `Icons` 与 `Labels`。裁切图标放在 `(552,212)`、`(552,259)`、`(552,306)`；大小分别为 **24×20、24×22、16×24**。名称 PNG 均为 32×16。坐标原点在左上；Unity 可设 RectTransform 左上锚点、左上 Pivot，然后使用 `(x,-y)`。

## 内容

- `Icons`：透明白色蒙版、普通琥珀、亮色、禁用暗色、选中深色；裁切版与 52×44 对齐单元版都提供。
- `Labels`：释放 / 治疗 / 净化的原版 16 点阵名称，各状态图片。
- `CommandRows`：三个按钮的完整四种状态，使用与 HTML 相同的图标、文字、背景和分隔线。
- `UI`：名册与审查背景框架、分隔线、反白条、页脚、只读指标背景与 05 示例。不包含动态对白或状态文字。
- `Monitor`：病房原图与 HTML 实际处理后的 464×261 暖灰监控图。不要再叠加一次黄色滤镜。
- `Fonts`：当前 HTML 的宋体 / Lucida Console 像素字形、坐标与覆盖字符；另有指标 00—99 的 66×32 字段图集。没有包含或安装系统 TTF/OTF 文件。
- `Runtime` / `Resources`：可选的位图文字显示组件及已绑定字体资源，只负责文字显示，没有游戏状态、处置或配额逻辑。
- `Effects` / `Shaders`：柔光关机线、光点和独立名称的 CRT 着色器。
- ZIP 根目录 `Reference`：本次 HTML、所选图片预览与原型对白数据。`Preview` 是执行本次 HTML 得到的实际本地绘制，不是概念图。

## 字体：避免再次换字形

位图文字组件需要 `com.unity.ugui` 和 `com.unity.modules.jsonserialize`，普通 Unity 模板通常已有。只使用 PNG 时不需要这两个辅助组件。

三个处置名称优先直接用 `Labels` PNG。其他文字可添加 **PMS UI v0.8.24 → Pixel Text** 组件，自动读取随包的 `HTMLBitmapFont`。设置 Pixel Size 为 10、11、12、13、14、16、18 或19，RectTransform Pivot 为左上。使用 `SetText(...)` 更新文字。颜色必须选择调色板中已导出的文字状态；默认是 #efb83f。

字形颜色已烘焙，组件通过颜色查找对应字形，不是把一张白字图集直接染色；不要替换成 TMP 或另一种系统字体来期待相同像素。字形度量为左上坐标，Unity UV 的 Y 轴需要翻转，随包组件已处理。

指标使用 `Fonts/QuotaFields_00_99.png` 及 `QuotaFields.json`；这些字段已经包含原来的粗体数字、背景与基线。它们是只读显示资源，数值由宿主 GameSession 提供。

## 显示与接入范围

默认图片导入采用标准 UGUI 的 sRGB 颜色路径，Image / RawImage 的 Tint 使用白色。不要对预着色 PNG 再染一遍琥珀色。白色 Mask 版可以自行染色。

CRT 着色器用于整个终端画面的最终合成，不要分别贴到每个图标。它延用原终端的 gamma 编码源图约定；如果接入之前已校准的 PMS 显示器，请沿用其整屏 RenderTexture / sRGB 设置。本包不会自动修改现有材质或渲染管线。使用其他整屏后处理时，可只使用 PNG 与布局文件。

这是 **UI 美术与文字资源包**，没有附带完整的终端玩法预制体，也不会自动替换正式游戏里的 UI。开关机和完整交互以 Reference 中的 HTML 为准，正式角色、配额和对白仍由宿主系统负责。UI 资源不保存第二份游戏规则。

具体坐标、颜色见 `Documentation/Layout.json` 与 `Palette.json`。本次校验结果和范围见 ZIP 根目录 `Validation`。

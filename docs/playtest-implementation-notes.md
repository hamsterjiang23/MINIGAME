# Discovered edge cases

- 原终端把已完成长句的当前分页文字继续当作整段记录，行高还被限制；需要保留完整记录，并提供滚轮回看。
- 30帧上限需同时关闭垂直同步；鼠标默认灵敏度从2降到0.7，并更新现有场景序列化值。
- 暂停翻转需用非开发版覆盖房间与终端两种背景，不能只沿用此前开发版结论。
- 滚轮事件的通知在帧末才发生；是否跟随最新记录改为读取实际滚动位置，避免同帧刷新跳回底部。
- 梦后自动跨日若命中普通结局，需要补发 Ending 演出事件；已增加最终夜晚的专门回归。
- 无图形模式下监控相机 Camera.Render 引发原生崩溃；图形相关 PlayMode 检查改用有图形设备的批处理进程。

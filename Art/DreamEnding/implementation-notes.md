# 海滩终局实现记录

## Deviations

- 海浪循环使用本工程生成的原创频域噪声与周期包络，不依赖外部录音。音乐与配音槽保持可替换；没有用其他歌曲填补未提供的终局歌曲。
- Blender 提供可雕刻沙滩源文件及导出网格。实时海浪、流云由 Unity 材质驱动，以统一暂停时钟冻结演出。

## Discovered edge cases

- 床直接复用 Combined 的四个原始网格、材质与世界缩放，再按枕头方位重定向。没有把家具交互组件或房间灯光带入终局。
- 床前停止距离随交互距离缩短，避免策划设为 0.5 米后无法到达交互范围。
- 加载进行中的配音会定位到字幕已播放时间；暂停加载时重新应用音源暂停，避免配音短暂恢复播放。
- 字幕完成标记与漂流时间进入快照；恢复后不会重新开始已完成的五句字幕。
- 自动测试通过显式输入推进生产代码，禁用物理键盘更新，避免当前桌面 W/E 输入干扰断言。
- 首次 Unity 实景验证暴露 FBX 前后轴反向：沙地升向海面并遮住远海。场景生成器现读取导入网格的高度/Z 协方差，仅在海岸向 +Z 上升时旋转地形 180 度，不依赖 FBX 前向约定；无需重导 Blender 文件。
- 同次画面检查调整过亮的沙地照明与沙粒反照率，并把均匀泡沫条带改为随浪移动的破碎泡沫。新画面仍需重新生成场景后复验。

## Questions for review

- Unity 实际导入后的 FBX 朝向、明亮海滩效果、仰望天空构图由主代理统一运行 CLI 和录屏确认。
- 《An Ending (Ascent)》和五句配音尚未提供文件，保持配置槽为空。

## Local checks

- Blender 4.5.11：生成脚本完成，退出码 0；源文件约 1.78 MB，FBX 约 440 KB。
- 原创海浪 WAV：双声道、44.1 kHz、30 秒；峰值 0.300，RMS 0.0325；源文件与 Unity 文件 SHA-256 相同。
- Unity 编译、PlayMode 测试、Scene 生成与 Player 验证交由主代理串行执行；本代理未调用 Unity CLI。
